      How to test

      • Keyboard only: Tab, Shift+Tab, Enter, Space, arrows and Esc.
      • Screen readers: NVDA, VoiceOver or TalkBack.
      • Browser zoom up to 200%.
      • Contrast testing tools.
      • Automated tools such as axe DevTools, Lighthouse and WAVE.
      • Remember that automated tools cannot detect every WCAG problem.
      Important limitation

      This lab cannot replace testing with real assistive technology. Manual testing with actual screen readers, keyboard navigation and magnification tools is required.
